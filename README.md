## Важные условия
1. Чтобы бот мог работать в группе (или канале), нужен **администратор чата**, у которого настроен URL вебхука Bitrix24 (`/url`). Если в беседе нет человека с правами администратора и прописанным URL, бот не сможет создавать/обрабатывать задачи.
2. Каждому пользователю, который хочет получать уведомления и назначаться ответственным в задачах, нужно установить свой Bitrix ID через команду `/bitrixid <ID>`. Без этого бот не сможет корректно поставить пользователя ответственным за задачу.
3. Контейнер бота работает в часовом поясе **Europe/Moscow**. 

## Команды

- **/start**  
  Запуск бота и приветственное сообщение.

- **/info**  
  Получить информацию о вашем профиле (настройках) в боте.

- **/ainfo**  
  Получить информацию о другом человеке (по реплаю или упоминанию).

- **/enable**  
  Включить бота (разрешить ему обрабатывать сообщения) для конкретного человека.

- **/disable**  
  Отключить бота для конкретного человека.

- **/url**  
  Задать URL вебхука из Bitrix24.  
  > Чтобы получить URL: в Bitrix зайти в «Приложение → Разработчикам → Другое → Входящий Webhook».  
  > Дать права (sonet, user, task, tasks) и скопировать полученный URL целиком.
  > Эту команду должен ввести администратор чата в личные сообщения боту.

- **/bitrixid**  
  Задать свой ID в системе Bitrix (чтобы бот понимал, кто вы в Bitrix).
  > Формат: `/bitrixid 123` (где `123` — ваш ID в Bitrix).

- **/notifications**  
  Назначить текущую беседу для отправки уведомлений о новых задачах.

- **/main**  
  Назначить текущую беседу для отправки ежедневных уведомлений о просроченных задачах.

- **/delay**  
  Вывести список просроченных задач (на текущий момент).

- **/report**  
  Вывести количество выполненных задач за неделю по каждому сотруднику.

- **/tasks**
  - Без аргументов: показать все ваши задачи (не завершённые либо завершённые за последнюю неделю).
  - С аргументом (имя человека/название команды или ID пользователя): показать те же задачи для указанного сотрудника или проекта.
- **/sprint**
  Подготовить спринт в текущем чате. Задачи можно добавлять до команды `/startsprint`.
- **/set_sprint_deadline** `YYYY-MM-DD HH:MM`
  Установить дедлайн подготовленного спринта.
- **/startsprint** `[YYYY-MM-DD HH:MM]`
  Запустить спринт. Можно указать дату вместе с командой.
- **/check**
  Показать статус задач текущего спринта.
- **/endsprint**
  Завершить спринт вручную (аналогично истечению дедлайна).

## Автоматическое создание задач

Если в беседе написать сообщение с тегом `#задача`, бот автоматически распознает:
- Название задачи  
- Описание (текст сообщения)  
- Исполнителей (по упоминанию или по ответу на сообщение)  
- Дедлайн

и создаст задачу в Bitrix.

## Автоматический еженедельный отчёт

Раз в неделю бот автоматически присылает команду `/report` руководителю, формируя отчёт о выполненных задачах за прошедшую неделю.
